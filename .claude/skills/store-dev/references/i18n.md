# i18n — FR (default), AR, EN

## Routing
- `next-intl`, locales `['fr','ar','en']`, default `fr`, `localePrefix: 'always'`. `/` → `/fr`.
- Middleware handles locale; `/admin` is excluded from locale routing.
- Language switcher: same page in the other locale (map translated slugs for product/category/collection pages; fall back to the FR slug if no translation). Save choice in `NEXT_LOCALE` cookie. No auto-redirect from `Accept-Language`.
- `<html lang={locale} dir={locale === 'ar' ? 'rtl' : 'ltr'}>`.
- `hreflang` alternates + `x-default` (FR) on every page.

## What gets translated
| Translated | Stays in original language |
|---|---|
| All UI strings (`messages/*.json`) | Brand name, logo |
| Product name, description, slug | SKU |
| Category / collection names, slugs, descriptions | Size labels (S, M, L, 42) |
| Color names | Third-party brand names |
| Banners, About and policy pages, size guides | Customer-entered data (names, addresses, notes) |
| Emails to customer (in order locale) | Admin UI (French only) |
| Image `alt` text | Order numbers |

## Content fallback
`getTranslation(entity, locale)` returns the locale row or the FR row. Never render an empty name because a translation is missing. Admin shows a "traduction manquante" indicator per locale.

## UI strings
- Keys namespaced by area: `header.*`, `product.*`, `cart.*`, `checkout.*`, `footer.*`…
- Use ICU plurals (`{count, plural, ...}`) — Arabic has six plural forms; provide them.
- A key added in one file must be added to all three (a test/script checks key parity).

## RTL
- Tailwind logical utilities only: `ms-* me-* ps-* pe-* start-* end-* text-start text-end border-s border-e rounded-s rounded-e`.
- Directional icons (chevrons, arrows, carousel controls) flip in RTL (`rtl:-scale-x-100`). Non-directional icons (cart, search) do not.
- Drawers slide from the inline-end side. Carousels scroll direction follows `dir`.
- Fonts: Inter for FR/EN, IBM Plex Sans Arabic for AR (via `next/font`, `--font-sans` switched per locale).

## Formatting
- Prices: `formatMoney(centimes)` → `199 MAD` in all locales, Latin digits (`Intl.NumberFormat` with `numberingSystem: 'latn'`).
- Dates: `Intl.DateTimeFormat(locale, { numberingSystem: 'latn' })`.
- Phone numbers always LTR (`dir="ltr"` on the element) inside Arabic text.
